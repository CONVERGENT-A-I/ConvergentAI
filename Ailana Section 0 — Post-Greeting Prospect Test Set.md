# Ailana Section 0 — Post-Greeting Prospect Test Set

Oct 29, 2026 · @David Patten

## Purpose and how to use

This is a 30-utterance smoke test of the prospect's first reply after Ailana's greeting. Each line is something a mortgage prospect might say, and the expected behavior is what Ailana should do with it on that first turn: identify intent, route to the right track and stage, and stay inside the compliance layer.

Each line packs several facts into one reply, the way real prospects talk: intent, occupancy, income, debts, credit, funds, location, and timing, often with self-corrections, ambiguity, or a compliance trap mixed in. The test is whether Section 0 extracts every stated fact, skips questions already answered, asks the right next question, and stays inside the compliance layer. Lines cover Purchase, Refinance, HELOC, Home Equity, and Construction bridge across Stages 1, 2, 2.5, and 3.

Testers read each line to Ailana verbatim right after the greeting, by voice and by text, and log the outcome in the Result column. Stage references assume the v8.7 master; if Section 0's scope differs from first-turn intent capture and routing, adjust the Expected column before running.

## Pass criteria and logging

A line passes when Ailana lands on the expected track or clarifying question in one turn and breaks no compliance rule. Partial means right intent but wrong wording, extra steps, or a stage jumped too early. Fail means wrong route, a rate quote, an SSN or address captured, a guarantee made, or documents requested.

- Use voice framing after any soft pull: "does that sound right" or "is that information correct", never "does that look right".
- Run each line twice, once by voice and once typed, since phrasing parses differently.
- Log every Partial and Fail in the prompt revision tracker with the exact utterance, Ailana's full reply, the stage, and the proposed fix text.
- Any compliance-trap Fail blocks pilot sign-off until fixed and retested.
