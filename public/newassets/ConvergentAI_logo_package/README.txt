ConvergentAI logo package
==========================

Selected direction: refined Decision Gate mark
Brand concept: structured inputs enter an intelligent decision gate.

Recommended primary use
-----------------------
Use ConvergentAI_primary_logo.svg for web and presentation materials.
Use ConvergentAI_primary_logo_mono_navy.svg for print, embossing, or situations where one-color reproduction is preferred.
Use ConvergentAI_app_icon_navy.svg or ConvergentAI_icon_mark.svg for square/social/app use.
Use favicon.ico or ConvergentAI_favicon_32x32.png for browser tabs.

Typography
----------
Recommended brand font: Inter / Inter Display, SemiBold for the wordmark.
The SVG uses live text with fallback: Inter Display, Inter, Arial, sans-serif.
For production brand files, a designer can convert the wordmark to outlines after final kerning approval.

Color palette
-------------
Primary Navy: #001A5B | RGB 0, 26, 91
Action Blue: #2453F3 | RGB 36, 83, 243
Intelligence Purple: #5F43D9 | RGB 95, 67, 217
Support Lavender: #8C95F1 | RGB 140, 149, 241
Digital Teal: #22C5CC | RGB 34, 197, 204

Notes
-----
These are clean vector recreations based on the selected AI-generated branding board. They are suitable for review, web mockups, and preliminary use. For legal/trademark and final print production, have a designer finalize kerning, optical alignment, and path geometry in Illustrator/Figma and export production-ready outlined SVG/EPS/PDF files.
